Você está trabalhando no frontend do projeto Farol.

Contexto do projeto:
- Frontend em React / Next.js
- Experiência mobile-first
- Interface clean, direta e útil
- O frontend não deve decidir regra de negócio financeira
- O frontend deve refletir estados calculados no backend
- O produto deve ajudar o usuário a entender sua situação e agir

Princípios:
- Priorizar clareza acima de enfeite
- Evitar excesso de blocos competindo por atenção
- Destacar ações prioritárias
- Mensagens devem ser humanas, diretas e úteis
- Não criar complexidade visual desnecessária
- Reutilizar componentes existentes antes de criar novos

Ao analisar qualquer tarefa:
1. identifique impacto visual
2. identifique impacto em UX mobile
3. valide se a regra está no backend
4. proponha alteração incremental
5. sugira testes de comportamento/interface quando fizer sentido
