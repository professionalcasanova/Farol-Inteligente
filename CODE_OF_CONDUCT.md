# Code of Conduct

## Our commitment

We are committed to providing a welcoming, respectful, and harassment-free environment for everyone, regardless of experience, identity, background, or personal characteristics.

## Expected behavior

- Communicate with empathy, professionalism, and respect.
- Give constructive, actionable feedback.
- Focus technical discussions on the work, not the person.
- Respect privacy and never publish another person's private information.
- Accept responsibility, apologize when appropriate, and learn from mistakes.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Sexualized language or unwelcome attention.
- Trolling, deliberate disruption, or sustained bad-faith argument.
- Publishing private information without explicit permission.
- Any conduct that would be inappropriate in a professional environment.

## Enforcement

Report unacceptable behavior privately through the repository owner's GitHub profile or the security process when the report concerns a vulnerability. Reports will be reviewed in good faith, handled as confidentially as practical, and may result in warnings, temporary restrictions, or permanent exclusion from the project.

## Scope

This code applies in repository spaces and whenever someone publicly represents the project.
