# Support

Farol is maintained as an open-source portfolio project and does not provide guaranteed support or financial advice.

## Questions and usage help

Before opening an issue:

1. Read the main [README](README.md) and component documentation.
2. Search existing issues for the same problem.
3. Confirm the problem still occurs on the current `dev` branch.

Use a GitHub issue for reproducible bugs and focused feature proposals. Include environment details, expected behavior, actual behavior, and minimal reproduction steps.

## Security

Do not report vulnerabilities or exposed credentials in public issues. Follow [SECURITY.md](SECURITY.md).

## Private or financial data

Never attach real bank statements, credentials, access tokens, database dumps, or personal financial records. Use synthetic examples only.
